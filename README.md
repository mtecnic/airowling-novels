## What's in each book directory

Every book folder carries the same working set:

- `novel.md` — the full manuscript
- `architecture.md` — the pipeline's planning document (premise, themes, chapter outline, cast)
- `bible.json` — structured world state (characters, settings, plot points)
- `chief_editor_letter.md` — the pipeline's own final editorial letter, candid about the manuscript's weaknesses
- `README.md` — literary overview and reading order
- `LICENSE` — CC BY 4.0

The multi-book collections (`pearl-casey-files/`, `silence-of-lolth/`) have their own subdirectory layout — see each folder's README.

## How these were made

Every manuscript is end-to-end drafted by [AIRowling](https://github.com/mtecnic/AIRowling). The pipeline handles the whole stack: premise expansion, story bible, chapter architecture, per-chapter drafting with continuity checks against a running world state, and a multi-editor pass at the end (developmental, copy, proofreader, chief). The chief-editor letters in each book folder are preserved from that final pass and are honest about the seams.

The pipeline itself is under active development. The corpus audit at [AIRowling → corpus-audit](https://github.com/mtecnic/AIRowling) covers a systematic survey of defects across these 16 novels and the P1–P14 detector series that ships fixes for each pattern.
